# Owl Marquee example

使用 `package:owl_marquee/owl_marquee.dart` 的独立 Flutter 应用，不依赖 MyCards、App 主题、素材或后端。

## 运行

```sh
flutter pub get
flutter run -d chrome
```

或运行 `flutter run -d web-server` 后打开终端给出的地址。example 在自身 pubspec 中启用 Web，不修改用户全局 Flutter 配置。仓库已包含 Web 入口；原生平台使用者可在自己的 Flutter App 中直接使用示例中的 Widget 组合。

## 场景

| 场景 | 可观察的行为 |
| --- | --- |
| 四个方向 | 同时对照上下左右，统一调速、间距和暂停 |
| 自然尺寸文字 | 横向不指定高度；纵向提供有限高度；RTL 不反转物理方向 |
| 不同尺寸卡片 | 不同宽高 Widget 连续循环，视口边缘保留阴影 |
| 动态布局 | 改变视口宽度、内容尺寸及空集合；LayoutBuilder 约束保持一致 |
| 空状态组合 | 调用方组合固定渐变和真实可点击前景；操作计数即时更新 |
| 减少动画 | 完整静态内容替换轨道，替代按钮保留交互 |
| 页面与暂停 | TickerMode 手动开关、真实路由进入/返回；可再切换浏览器标签或前后台观察生命周期 |

顶部控件可调速度（0–100 px/s）、间距（0–40 px）、暂停、减少动画和 RTL。除“四个方向”对照外，可随时切换方向。不同场景仅挂载当前内容；切换场景不承诺保留其内部播放偏移。

“减少动画”控件只可追加限制，不覆盖系统已经要求的减少动画偏好。自然尺寸文字和无障碍场景提供完整静态替代，其余装饰轨道冻结。空状态按钮及静态按钮仅执行示例中的本地计数，不模拟业务接口。

每个场景的组合位于 `lib/main.dart` 的对应方法中；底层动画只来自包的 `OwlMarquee`。
